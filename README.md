# Yelpcamp

A full-stack campground review and discovery application built with Node.js, Express, MongoDB, and EJS. Users can browse campgrounds, add new ones, leave reviews, and manage their own listings with authentication and secure image uploads.

## Features

- Browse a list of campgrounds with descriptions and pricing
- Add new campgrounds with title, location, image, and details
- Edit and delete campground listings
- Leave reviews and ratings for campgrounds
- User registration and login
- Flash messages for success and validation feedback
- Cloudinary-powered image uploads
- Mapbox integration for location-aware display
- MongoDB-backed persistence
- Responsive UI built with Bootstrap

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Passport.js
- EJS
- Bootstrap
- Cloudinary
- Mapbox
- Connect Flash
- Express Session
